# Forest textures (Poly Haven, CC0)

Downloaded by Puli at 1K, converted to WebP. Per set: `_col` colour (sRGB), `_nrm` normal (OpenGL), `_orm` red =
ambient occlusion, green = roughness (three.js reads `aoMap.r` and `roughnessMap.g`, so one file serves both).

| Files | Poly Haven set | Use |
|---|---|---|
| `bark_*` | bark_brown_02 (has moss streaks) | regular trunks and branches, and the mossy trunks and logs |
| `bark2_*` | tree_bark_03 (Puli's pick) | a second bark for variety |
| `leaves_*` | forest_leaves_02 | forest floor |
| `ground_*` | forrest_ground_01 | ground between the leaves, the running path |
| `mossrock_*` | mossy_rock | rocks and boulders |
| `rock_*` | rock_boulder_dry | bare rock, obstacles |
| `mud_*` | brown_mud_leaves_01 | muddy patches, the game's gaps |
